# Shell Formatter v1.0.1

## 更新摘要

此版本主要修复了文档格式问题、测试脚本错误，优化了构建配置，并新增了 CI/CD 工作流支持。

- **修改文件**: 16 个

## ✨ 新特性

### CI/CD 支持

- **GitHub Actions 工作流** - 新增自动化构建和代码检查工作流
  - `ci.yml` - 持续集成工作流
  - `codebuddy-ci.yml` - CodeBuddy 代码检查工作流
