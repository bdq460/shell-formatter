## 架构重构

### 1. 六边形架构重构

- **动机**: 提升代码可维护性、可测试性，明确分层职责
- **变化**:
  - 引入领域驱动设计（DDD）概念
  - 划分为 Entrypoints、Application、Domain、Infrastructure 四层
  - 明确依赖方向：外层 → 内层
  - 新增适配器层（Adapter Layer）隔离外部依赖
- **收益**:
  - 职责更清晰，模块间耦合度降低
  - 测试更容易，支持单元测试和集成测试分离
  - 扩展性更强，便于添加新功能
- **相关提交**: 0e357db, a999d5b, 6de6701

## 问题修复

### 修复虚拟文档诊断残留

- **问题**: 格式化后诊断信息不更新，导致显示过时的错误提示
- **原因**: 虚拟文档的变更事件未正确触发诊断刷新
- **解决方案**: 重构诊断适配器，优化文档过滤和事件处理机制
- **影响**: 提升诊断信息的准确性和实时性
- **相关提交**: a9c7acc

## 升级指南

### 从 v1.0.1 升级

1. 更新插件：

   ```bash
   code --install-extension shell-formatter-1.0.2.vsix
   ```

2. 重启 VSCode

3. 验证安装：
   - 打开命令面板（Cmd/Ctrl + Shift + P）
   - 输入 "Shell Formatter: Show Plugin Status"
   - 确认插件状态正常

### 新功能试用

1. **查看插件状态**：
   - 命令面板 → "Shell Formatter: Show Plugin Status"

2. **性能监控**：
   - 命令面板 → "Shell Formatter: Show Performance Metrics"

3. **切换语言**：
   - VSCode 设置 → `shellFormatter.language`
   - 支持 17 种语言
