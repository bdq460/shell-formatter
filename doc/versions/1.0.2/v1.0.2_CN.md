### 虚拟文档诊断修复详情

**变更** (a9c7acc): 修复 AI 助手虚拟文档（genie-diff）导致的诊断错误无法消失问题

**问题描述**:

当使用 AI 助手（如 CodeBuddy）时，虚拟文档（URI scheme 为 genie-diff）会导致诊断信息无法正常清除，造成错误提示残留。

**解决方案**:

1. 添加 URI scheme 过滤，只处理 `file` 和 `git` 协议的文档
2. 重构文档过滤逻辑，增加三层过滤机制：
   - 语言 ID 过滤
   - 扩展名过滤
   - URI scheme 过滤

**支持的 URI scheme**:

| Scheme | 说明 |
|--------|------|
| file | 本地文件系统 |
| git | Git 版本控制文件 |

### 六边形架构详情

**变更** (a999d5b): 实现完整的六边形架构分层设计

**架构分层**:

```text
src/
├── adapters/       # 适配器层 - 工具接口适配
├── application/    # 应用层 - 用例实现
├── domain/         # 领域层 - 核心业务逻辑
├── ports/          # 端口层 - 领域接口定义
├── shared/         # 共享层 - 日志和性能指标
└── utils/          # 工具层 - 基础设施
```

**新增组件**:

- 适配器层实现工具接口适配
- 共享层支持日志和性能指标
- 端口层定义领域接口
- 国际化（i18n）支持
