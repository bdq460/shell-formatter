### Virtual Document Diagnostic Fix Details

**Change** (a9c7acc): Fix diagnostic persistence caused by AI assistant virtual documents (genie-diff)

**Problem**:

When using AI assistants (like CodeBuddy), virtual documents (URI scheme: genie-diff) caused diagnostic information to persist incorrectly.

**Solution**:

1. Add URI scheme filtering for `file` and `git` protocols only
2. Three-layer document filtering:
   - Language ID filtering
   - Extension filtering
   - URI scheme filtering

**Supported URI schemes**:

| Scheme | Description |
|--------|-------------|
| file | Local file system |
| git | Git version controlled files |
