# Shell Formatter v1.0.2

## Summary

This release focuses on refactoring the project architecture to adopt Hexagonal
Architecture (also known as Ports and Adapters), significantly improving code
maintainability and testability. It also enhances internationalization (i18n)
support with 17 new languages and optimizes virtual document diagnostics.

## Code Refactoring

### 1. Hexagonal Architecture Implementation

- **Motivation**: Improve code maintainability, testability, and clarify layer
  responsibilities
- **Changes**:
  - Introduced Domain-Driven Design (DDD) concepts
  - Divided into four layers: Entrypoints, Application, Domain, and Infrastructure
  - Clear dependency direction: Outer layers → Inner layers
  - Added Adapter Layer to isolate external dependencies
- **Benefits**:
  - Clearer responsibilities and reduced coupling between modules
  - Easier testing with separation of unit and integration tests
  - Better extensibility for adding new features
- **Related Commits**: 0e357db, a999d5b, 6de6701

### 2. Module Import Path Optimization

- **Motivation**: Simplify module imports and improve development experience
- **Changes**:
  - Refactored TypeScript path alias configuration
  - Unified use of `@/` prefix to represent project root
  - Optimized module resolution strategy
- **Benefits**:
  - Cleaner and clearer import paths
  - Avoid deep relative paths (e.g., `../../../`)
  - Improved code portability
- **Related Commits**: bc30a3f

### 3. Dependency Injection Container Refactoring

- **Motivation**: Improve dependency management flexibility and support better testing
- **Changes**:
  - Refactored DI container implementation
  - Optimized initialization process
  - Support for dependency lifecycle management
- **Benefits**:
  - Easier unit testing (supports Mocking)
  - Clearer dependency relationships
  - Support for lazy initialization
- **Related Commits**: 6de6701, ad5a340

### 4. Testing Framework Enhancement

## Bug Fixes

### Fixed Virtual Document Diagnostic Residue

- **Issue**: Diagnostic information was not updated after formatting, causing
  outdated error messages to be displayed
- **Cause**: Virtual document change events were not properly triggering
  diagnostic refresh
- **Solution**: Refactored diagnostic adapter and optimized document filtering
  and event handling mechanism
- **Impact**: Improved accuracy and real-time performance of diagnostic information
- **Related Commits**: a9c7acc

## Upgrade Guide

### Upgrading from v1.0.1

1. Update the extension:

   ```bash
   code --install-extension shell-formatter-1.0.2.vsix
   ```

2. Restart VSCode

3. Verify installation:
   - Open Command Palette (Cmd/Ctrl + Shift + P)
   - Type "Shell Formatter: Show Plugin Status"
   - Confirm plugin status is normal

### Trying New Features

1. **View Plugin Status**:
   - Command Palette → "Shell Formatter: Show Plugin Status"

2. **Performance Monitoring**:
   - Command Palette → "Shell Formatter: Show Performance Metrics"

3. **Switch Language**:
   - VSCode Settings → `shellFormatter.language`
   - Supports 17 languages
