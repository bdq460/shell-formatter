## Change Details

### Git Virtual Document Diagnostic URI Mapping Fix Details

**Change** (4c984c6): Add URI normalization mechanism to resolve VSCode Git extension virtual document diagnostic display issues

**Problem Description**:

The VSCode Git extension creates virtual documents for the same shell file (with scheme `git` and a `.git` suffix in the filename), for example:

| Type | URI Example |
|------|-------------|
| Real file | `file:///path/to/service.sh` |
| Git virtual document | `git:/path/to/service.sh.git` |

This caused:

- Problems panel showing wrong filename `service.sh.git`
- Diagnostic line numbers not matching the actually opened file content
- Users unable to navigate to correct code location by clicking problems

**Solution**:

Added `normalizeToFileUri()` function in `src/shared/file-checker.ts` to map `git:` scheme virtual document URIs back to real `file:` URIs:

```typescript
export function normalizeToFileUri(uri: vscode.Uri): vscode.Uri {
    if (uri.scheme === "file") return uri;

    const fileName = uri.fsPath.split("/").pop() || "";
    const gitSuffix = /\.git$/;
    if (uri.scheme === "git" && gitSuffix.test(fileName)) {
        const realPath = uri.fsPath.replace(gitSuffix, "");
        return vscode.Uri.file(realPath);
    }
    return uri;
}
```

**Affected Scope**:

Modified 5 `diagnosticCollection.set()` call sites to ensure all diagnostics use normalized file URIs:

| File | Description |
|------|-------------|
| `src/shared/file-checker.ts` | Add `normalizeToFileUri()` function |
| `src/entrypoints/listeners/open-listener.ts` | Use normalized URI on document open |
| `src/entrypoints/listeners/save-listener.ts` | Use normalized URI on document save |
| `src/entrypoints/listeners/change-listener.ts` | Use normalized URI on document change |
| `src/entrypoints/commands/fix-command.ts` | Use normalized URI for diagnostic updates in fix command |
